# Cedanet Solutions - Instrucciones del Proyecto

## Resumen
Sitio web corporativo para Cedanet Solutions, empresa de soluciones tecnológicas integrales en República Dominicana.

## Paleta de Colores
- **Primario:** #0097A7 (cyan/azul tecnológico)
- **Primario hover:** #00838F
- **Acento claro:** #4DD0E1
- **Fondo oscuro (hero/CTA/footer):** #0a1628
- **Fondo secciones alternas:** blanco (#fff) y gris claro (#f0f9fa / gray-50)
- **Texto principal:** gray-900
- **Texto secundario:** gray-600
- **WhatsApp:** #25D366

## Tipografía
- Display: Plus Jakarta Sans (headings)
- Body: DM Sans
- Mono: JetBrains Mono

## Estructura de Secciones
1. Header (sticky, transparente → blanco al scroll)
2. Hero (imagen de fondo, gradiente oscuro)
3. Quiénes Somos (4 bloques destacados)
4. Servicios (8 tarjetas con imagen + icono)
5. Por qué elegirnos (6 bloques)
6. Proyectos (8 items galería)
7. Proceso (5 pasos timeline)
8. CTA (fondo oscuro con gradiente)
9. Contacto (formulario + info lateral + WhatsApp)
10. Footer (4 columnas)
11. Botón flotante WhatsApp

## Estilo de Diseño
- Moderno, profesional, minimalista
- Animaciones con Framer Motion + Intersection Observer
- Smooth scroll entre secciones
- Responsive (mobile-first)
- Colores CSS variables personalizados (sin dark mode, solo light)
